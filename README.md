Este repositorio concentra las evidencias de las tareas/prácticas de la materia. Cada tarea vive en su propia rama, aislada de `main`. En `main` únicamente se mantiene esta guía.

## Convención

- Cada nueva evidencia se trabaja en una rama `sXX-nombre-corto` a partir de `main`.
- Al terminar, se agrega una fila a la tabla anterior con el nombre de la rama y una descripción breve de lo que contiene.
- `main` no acumula código de las tareas: solo este README.
